1. 开始前准备

  • 自己的邮箱、手机号和用于欧易高级身份认证的本人证件。
  • 来源合法的资金，以及你所在地区当前支持的购买或转入 USDT 方式。
  • 提前打开 Roogoo 充值页面，确认资产、网络、地址、最低充值金额和 Memo/Tag 要求。
  • 第一次转账准备小额测试，不要一开始就转入全部余额。
重要：数字资产可能产生损失，账户可用功能、费率、限额、活动和认证要求会因地区和账户而变化。本教程是操作说明，不是投资或金融建议。

2. 注册并完成欧易认证

  1. 打开 我的欧易推荐注册链接。
  2. 创建账户前，确认页面已经带有推荐或活动归因。欧易说明，注册后通常不能再补填或更改推荐关系。
  3. 使用自己的邮箱或手机号注册，设置独立密码，并只用本人真实资料完成高级身份认证。
  4. 注册完成后打开 活动中心 → 新人奖励 / Welcome Rewards 或当前推荐页面，查看账户实际分配的任务。
  5. 不要把“最高 100 USDT”理解成注册后自动到账。活动可能要求充值、交易、持仓、领取或其他条件。

3. 在欧易购买或接收 USDT

在欧易内购买

根据已认证账户和所在地区当前可用的付款或交易方式操作，确认最终金额、费率、价格和到账时间后再确认。

从其他平台转入

打开 充值 → 充币 → USDT，选择网络，并先确认转出平台支持同一个网络，再复制充值地址。

检查最低金额

欧易充值页面会显示最低金额和所需确认数。低于最低金额的转账可能无法到账。

预留手续费

给 Roogoo 需要的金额之外留出网络费和卡片使用缓冲。不要使用猜测的网络或旧截图里的地址。

4. 把 USDT 转入 Roogoo

  1. 在 Roogoo 打开资产充值页面，选择 USDT，复制当前显示的充值地址。
  2. 在欧易打开 资产 → 提币 → 提取数字货币，选择 USDT，粘贴 Roogoo 地址。
  3. 两边必须选择完全相同的网络。例如 Roogoo 显示 TRC20 时，欧易也要选择对应的 TRC20；币种和网络都要匹配。
  4. 输入金额，检查手续费和最低金额，并完成地址、二次验证或提币验证。
  5. 第一次先转一笔小额测试款，确认 Roogoo 到账后，再转入剩余金额。
  6. 保存 TxID，等待区块确认。到账不是即时的，不要因为暂时没显示就重复转账。
网络不匹配可能造成资金损失：欧易提示，不支持的币种、错误网络、错误合约或缺少 Memo/Tag，可能无法自动入账，找回也不一定成功。

5. 把余额转入 Roogoo 卡片

  1. 确认欧易提币完成，并且 Roogoo 资产账户已经显示到账，再打开卡片或资产转账页面。
  2. 只把需要的金额转入 Roogoo 卡片，同时保留该卡要求的最低余额和付款手续费缓冲。
  3. 绑定 Apple Account 或付款前，检查卡片状态、支持的商户类型、有效期、预授权规则和最新费率。
  4. 回到 Roogoo 开卡与美国 App Store 支付教程，继续完成绑定和购买。

6. 查看奖励与处理问题

怎样获得宣传中的奖励？

当前宣传为最高 100 USDT，不代表固定、无条件发放。注册后打开欧易活动中心，只完成账户显示的任务；奖励金额可能因国家、活动、账户类型和市场情况不同而变化。

充值后没有到账

依次检查币种、网络、地址、最低金额、Memo/Tag、TxID 和确认数。都正确仍未到账时，通过欧易或 Roogoo 官方支持提交记录。不要再次转账来“加速”。

没有关联推荐关系

推荐关系通常必须在注册时建立。如果没有通过推荐链接注册，不要为了奖励重复创建多个账户，应先联系平台支持并遵守账户规则。

7. 安全清单

  • 只使用官方 App 或网站，开启身份验证器和防钓鱼码，不要泄露密码、验证码或助记信息。
  • 确认页面上完整的地址和网络，不要只看地址开头和结尾几个字符。
  • 不要使用他人的身份、银行卡、账户或账单资料。
  • 保存 TxID、截图和客服工单号，但只通过已核验的官方渠道提交。
