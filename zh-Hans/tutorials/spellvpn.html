SpellVPN 使用教程

新手从这里开始

最常用的操作只有 5 步：下载 App → 准备订阅 URL → 导入 → 选择线路 → 连接。下面按手机里的实际按钮写清楚，照着操作就可以开始使用。

下载 iOS 付费版查看产品介绍遇到问题隐私政策
先看这里：你需要准备什么？

准备以下任意一种即可：服务商提供的订阅 URL、单条代理链接、二维码、sing-box JSON、Clash/Mihomo YAML 或本地配置文件。SpellVPN 是配置客户端，不内置服务器、不销售节点；请只导入你有权使用的配置。

1

下载 App 并打开

  1. 在 iPhone 或 iPad 上打开 App Store 下载地址，安装 SpellVPN Tool。
  2. 首次打开 App 后先允许必要的系统权限。真正连接 VPN 时，iOS 还会弹出“允许添加 VPN 配置”的系统窗口，请点击允许。
  3. 如果你使用的是免费 Ultra 版本，也可以从官网产品页的 Ultra 下载入口安装；本教程的导入和连接流程基本相同。
2

最常用：导入订阅 URL

  1. 从你的服务商后台复制完整订阅地址。它通常以 https:// 或 http:// 开头，并可能带有很长的 token。
  2. 打开 SpellVPN 首页，点击右上角 +，选择导入订阅 URL。
  3. 将 URL 粘贴到输入框，点击导入，等待 App 下载和解析。订阅节点较多时请耐心等待，不要连续点击导入。
  4. 看到“导入成功”后，进入节点标签页检查线路数量，再选择一条线路。
订阅 URL 不等于 App Store 订阅

订阅 URL 是服务商提供的配置地址，用来下载节点；App Store 订阅是 Ultra 版本的 App 权益。两者不是同一种订阅。

https://example.com/api/v1/client/subscribe?token=xxxx
3

只有一条线路怎么办？

如果服务商给你的是一条线路链接，不是订阅地址，也可以直接导入。

  1. 复制完整线路链接。
  2. 首页点击 +，选择导入代理链接。
  3. 粘贴链接并确认，App 会在本机解析并生成运行配置。
  4. 进入节点页面，点击这条线路或左滑点击使用。

常见格式包括 ss://、vmess://、vless://、trojan://、hysteria2://、hy2://、tuic://、socks5://、ssh:// 和 anytls://。

4

二维码、文件和剪贴板导入

  1. 二维码：首页点击 +，选择“扫描二维码”；二维码在相册里时选择“从相册导入二维码”。
  2. 配置文件：选择“导入文件”，从文件 App 或 iCloud Drive 选择 .json、.yaml、.yml、.conf、.wg 或文本文件。
  3. 剪贴板：先复制 URL、线路链接或配置文本，再选择“粘贴配置或 URL”。
  4. 电脑上传：进入设置 → 网络与配置 → Wi-Fi 上传，开启后在同一 Wi-Fi 下用电脑浏览器打开 App 显示的地址，上传文件或粘贴订阅。
格式提醒

当前 App Store 构建不原生运行 OpenVPN .ovpn 和 IKEv2 .mobileconfig。导入时出现明确不支持提示是正常的，不代表线路本身一定失效。

5

选择线路并连接

  1. 打开节点标签页，点击一条可用线路，或左滑后点击使用。
  2. 需要比较线路时，可以运行健康检查、刷新延迟，或使用“自动优选节点”。
  3. 回到首页，确认当前配置显示为就绪，然后点击连接。
  4. 第一次连接时，在 iOS 系统弹窗中允许添加 VPN 配置。
  5. 看到 App 和系统都显示“已连接”后，再打开网页或使用网络工具测试。
已连接但打不开网页？

先换一条节点测试，再检查路由模式、DNS、服务器端口和线路协议。系统显示“已连接”只代表隧道启动，不代表远端节点一定可用。

6

更新订阅和管理线路

  1. 进入设置 → 网络与配置 → 管理订阅。
  2. 点击已保存的订阅，可以更新 URL、复制 URL、重命名或删除订阅。
  3. 订阅页右上角的更新按钮可以逐个刷新所有已保存订阅。
  4. 刷新后回到节点页面，重新选择需要使用的线路。
  5. 节点支持搜索、收藏、编辑、导出和二维码分享；包含账号信息的线路不要公开分享。
7

路由模式怎么选？

路由模式决定哪些流量走代理、哪些流量直连。建议先使用订阅或配置提供的规则；出现访问异常时，一次只调整一个设置。

规则按导入配置和规则分流，适合日常使用。
全局 / 代理尽量通过当前线路，适合统一出口测试。
直连保持隧道运行，但最终出站使用 direct。
自定义尽量保留导入配置中的 route，适合高级用户。
8

常见问题排查

  1. 订阅打不开：确认 URL 没有过期、没有多余空格，并尝试在浏览器中打开；优先使用 HTTPS。
  2. 导入失败：查看 Logs，确认 JSON/YAML 格式正确，服务器和端口字段完整。
  3. 连接失败：确认已允许系统 VPN 权限，换节点测试，不要连续点击连接按钮。
  4. 显示已连接但没有流量：检查当前节点、路由模式、DNS、TLS/传输字段和服务端端口。
  5. 仍然无法判断：打开 Logs 和 Network Tools，导出诊断报告，再联系支持邮箱。

备份与版本说明

  1. 进入设置 → 数据与同步 → 导出 App 数据文件，可以备份配置、节点、订阅、规则、DNS、路由模式、虚拟网卡设置和流量统计。
  2. 也可以使用 iCloud Drive 备份，但它需要正式签名的 App ID 开启 iCloud Documents capability。
  3. iOS Pro 是付费无广告版本；iOS Ultra 免费版包含广告，并提供可选 App Store 自动续期订阅。
  4. macOS 版本是独立的原生客户端，没有广告 SDK、分析 SDK、StoreKit 商品、订阅或内置 VPN 账号。
一句话记住使用流程

首页右上角 + 导入订阅或线路 → 节点页选择线路 → 回首页连接 → 出问题先换节点，再查看路由、DNS 和 Logs。
