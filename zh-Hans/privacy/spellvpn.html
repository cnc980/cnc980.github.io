版本与功能说明

SpellVPN Tool · iOS / Mac

SpellVPN Tool 是 iOS 与 macOS 的付费无广告配置客户端，不提供服务器节点、预设来源目录或节点服务内购订阅。用户需要导入自己有权使用的配置、节点或订阅 URL。客户端可依据导入配置建立 VPN 连接，并非仅离线查看文件的工具。

SpellVPN Ultra · iOS

SpellVPN Ultra 是包含广告和可选 App Store 自动续期订阅的 iOS 版本。有效订阅可去除广告，并访问服务提供的“精选来源（Curated Sources）”和“专属线路（Exclusive Lines）”。Ultra 也支持用户自行导入。服务提供的配置是实际订阅权益，不能只概括为去广告。

配置来源与网络请求

配置来源与网络请求

SpellVPN Tool 会访问用户导入配置中的订阅、DNS 与服务器端点。SpellVPN Ultra 使用精选来源或专属线路时，还会向 apixx.spellv.com 请求服务内容，并可能继续访问返回的订阅和节点端点。远端服务会收到处理请求所需的网络信息，例如 IP 地址与 HTTP 请求元数据。VPN 流量由当前配置中选用的服务器处理。这些请求与 App Store 购买处理、Ultra 广告请求分别发生。

Ultra 订阅与权益

在 SpellVPN Ultra 中打开“设置 → 订阅 → Ultra 订阅”，查看套餐、购买或恢复购买。拥有有效权益后，可从正常界面访问精选来源或专属线路；“我的导入”与服务提供的内容分别管理。购买或来源加载失败时，请向支持人员提供 App 版本和错误提示，不要发送密码或完整订阅 URL。

Ultra 订阅与权益

周、月、季、年自动续期套餐由 Apple 处理。实际价格、周期和续期条款以 App Store 购买确认页为准；可在 App 内恢复符合条件的购买，并在 Apple 账户中管理订阅。来源内容和连接情况可能变化，订阅不代表永久节点、无限流量或特定地区可用性的承诺。

版本和付费模式

Tool：付费、无广告，仅使用用户自行提供的配置。iOS Ultra：含广告，可选订阅可去广告，并提供精选来源和专属线路。

存储在设备上的数据

SpellVPN 会存储你导入或创建的 VPN 配置、已保存订阅 URL、代理链接、节点、策略组、路由规则、DNS 设置、路由模式、虚拟适配器设置、流量统计和本地日志。这些数据用于启动 VPN 会话、切换节点、显示连接状态、导入或导出配置以及诊断连接问题。

iCloud Drive 备份

如果你选择使用 iCloud Drive 备份或恢复，完整 App 数据备份会保存到你自己的 iCloud Drive 的 SpellVPN/Backups 文件夹中。备份不包含已安装的 iOS VPN 权限配置，也不包含日志，除非你单独导出日志。我们无法访问你的 iCloud Drive 内容。

相机和照片

SpellVPN 仅在扫描二维码导入 VPN 配置或订阅链接时请求相机权限。从照片导入二维码时，应用只处理你选择的图片以识别二维码内容。

网络连接

SpellVPN Tool 会访问用户导入配置中的订阅、DNS 与服务器端点。SpellVPN Ultra 使用精选来源或专属线路时，还会向 apixx.spellv.com 请求服务内容，并可能继续访问返回的订阅和节点端点。远端服务会收到处理请求所需的网络信息，例如 IP 地址与 HTTP 请求元数据。VPN 流量由当前配置中选用的服务器处理。这些请求与 App Store 购买处理、Ultra 广告请求分别发生。

SpellVPN macOS 版

SpellVPN Tool Mac 版导入用户自行提供的配置，通过原生 macOS Packet Tunnel 建立连接，不含广告、App Store 订阅或内置节点服务。通过订阅提供精选来源和专属线路的是独立的 iOS Ultra 版本。

SpellVPN Ultra 广告

SpellVPN Ultra 已接入 Yandex Mobile Ads 和 Google AdMob。免费版可能展示横幅、原生或信息流、插屏和开屏广告。第三方广告 SDK 可能会为加载、展示、衡量、限频、个性化和保护广告而处理数据。

广告可能处理的数据

广告 SDK 可能处理 IP 地址以及由 IP 地址推断的粗略位置；设备和 App 信息，例如设备型号、系统版本、语言、屏幕尺寸、App 版本和网络连接状态；在允许的情况下处理 Apple 广告标识符 IDFA；App 或开发者范围内的设备标识符；广告请求和响应数据；已展示的广告、展示次数、点击、关闭事件、视频观看和其他广告互动；与广告投放相关的 App 启动和产品互动事件；性能信息，例如启动时间、卡顿率、能耗和广告加载耗时；以及诊断信息，例如 SDK 错误、崩溃日志和其他技术日志。

广告数据用途

这些数据可能用于广告投放、在允许时展示上下文广告或个性化广告、频次控制、广告衡量、归因、报表、反作弊、安全保护、调试、SDK 性能改进、合规以及广告收入统计。广告合作方可能会按照其各自的隐私政策处理这些数据，包括 Google 隐私权政策 https://policies.google.com/privacy 和 Yandex 隐私政策 https://yandex.com/legal/confidential/。

订阅和购买

Ultra 订阅由 Apple App Store 和 StoreKit 处理。SpellVPN 可能接收产品标识符、交易状态、购买、续订、到期、取消、退款、恢复购买和权益状态，用于解锁付费功能。我们不会收到你的银行卡号、账单地址或 Apple ID 密码。

选择和同意

在含广告的 Ultra 构建中，SpellVPN Ultra 会在广告 SDK 初始化前请求 App Tracking Transparency 权限。在法律或平台规则要求时，也可能在请求个性化广告或访问 Apple 广告标识符前征求你的同意。你可以在 iOS 隐私设置中限制广告追踪。如果你拒绝追踪或个性化广告，免费版仍可能展示非个性化广告或上下文广告，广告 SDK 也仍可能处理广告投放、安全、反作弊、衡量和合规所必需的有限数据。

Pro 版

SpellVPN Tool 是付费下载版本，不展示广告，也不会为广告投放初始化 Yandex Mobile Ads 或 Google AdMob。

日志

应用可能生成本地连接日志、校验信息、诊断日志和隧道快照，用于排查问题。除非你主动导出或分享，日志会保留在设备上。清除本地数据会移除本机配置、节点、订阅、规则、DNS 设置、流量统计、日志、隧道快照和已安装的系统 VPN 配置；iCloud Drive 备份文件会保留，除非你主动删除。

儿童隐私

SpellVPN 并非面向儿童，也不会明知收集儿童个人信息。

变更

如果未来版本更换广告合作方、增加新的广告 SDK、改变广告数据类型、调整订阅或购买功能，或加入账号、开发者运营的云同步、分析、崩溃报告或其他数据收集，本政策和 App Store 隐私标签会同步更新。
