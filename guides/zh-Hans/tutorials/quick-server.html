小白一键搭建

从登录服务器到导入 兼容客户端

准备一台自己的 Debian 或 Ubuntu 云服务器，复制两条命令即可部署。成功后终端会给出一个可直接导入 兼容客户端 的 HTTPS 订阅 URL，内含 7 条多协议、多端口节点；无需购买域名。

下载一键脚本 查看进阶教程
开始前请确认

只在你拥有或获准管理的全新服务器上使用。脚本仅支持 Debian / Ubuntu、root 和 systemd；若发现所需端口、已有 Xray 或已有 兼容客户端 订阅服务，会立即停止，不会覆盖。

2026-11-10 恢复整理；活动、费用及操作界面请查看服务方最新说明。

只需 4 步

  1. 准备服务器
  2. SSH 登录
  3. 下载并运行
  4. 导入 兼容客户端

1. 准备服务器

  • 购买一台带公网 IPv4 的 Debian 12/13 或 Ubuntu 22.04/24.04 云服务器。
  • 记下服务器公网 IP、root 密码，或准备好 SSH 私钥。
  • 在云厂商安全组中放行 TCP 22、80、443、8388、8443、2053、2083、2087、2096、9443，以及 UDP 8388。
  • 如果 SSH 不是 22 端口，请放行你实际使用的 SSH 端口。
不要把密码发给别人。在自己的终端里输入密码；输入时屏幕不显示字符是正常现象。

2. SSH 登录服务器

Mac 打开“终端”，Windows 打开 PowerShell，把下面的 IP 换成你的服务器公网 IP：

ssh root@你的服务器IP

第一次连接输入 yes，然后输入 root 密码并回车。看到类似 root@server:~# 就是登录成功。

示例：ssh root@203.0.113.10。示例 IP 不能直接使用。

3. 下载并运行一键脚本

登录服务器后，依次复制下面两行。先下载到服务器，再运行；不使用不可审阅的 curl | bash 方式。

curl -fsSL https://spellv.com/downloads/serverkit-quick-server.sh -o serverkit-quick-server.sh
bash serverkit-quick-server.sh

想先查看脚本内容，可以在第二行之前运行：

less serverkit-quick-server.sh

脚本会检查系统与端口、校验 Xray 官方安装包、生成独立随机凭据、识别服务器真实国家、配置 Xray 与 Nginx 自启动，并自动申请和续期受信任的 IP HTTPS 证书。若 UFW 已启用，会添加所需规则，但不会擅自启用防火墙。

TCP 80 必须能从公网访问。它用于申请和续期 IP 证书。云厂商安全组还需放行节点端口与订阅端口 9443，否则脚本或客户端连接会失败。

4. 导入 兼容客户端

安装成功后，终端会显示一个类似 https://服务器IP:9443/sub/随机密钥 的订阅 URL。

  1. 完整复制整条 HTTPS 订阅 URL，不要遗漏随机密钥。
  2. 打开 兼容客户端，点“添加”或“+”。
  3. 选择“订阅”或“从 URL 导入”，粘贴并保存。
  4. 更新订阅后会看到 7 条节点，任选一条连接测试。

以后忘记订阅地址，可重新 SSH 登录服务器并运行：

cat /root/serverkit-subscription-url.txt
国家标识是真实出口位置。一台服务器的 7 条节点会显示同一个国家代码；要得到美国、日本、新加坡等不同国家线路，需要分别在这些国家购买服务器并运行脚本。

连接不上时检查

systemctl status xray nginx --no-pager
journalctl -u xray --no-pager -n 50
ss -lntup | grep -E ':443|:8388|:8443|:2053|:2083|:2087|:2096|:9443'
  • 确认 兼容客户端 中的服务器地址就是云服务器公网 IP。
  • 确认云安全组放行教程列出的全部节点端口，以及证书端口 80 和订阅端口 9443。
  • 先在 Wi-Fi 和蜂窝网络之间切换，排除当前网络限制。
  • 凭据保存在仅 root 可读的文件中，不要公开分享或提交到代码仓库。

这个脚本搭建了什么？

7 条多协议节点包含 VLESS Reality、Shadowsocks、VMess WS/TLS、VLESS TLS、Trojan TLS、VLESS gRPC/TLS 和 Trojan WS/TLS。
HTTPS 订阅 · TCP 9443自动签发受信任的短期 IP 证书，并配置后台续期与服务重载。
真实国家标识根据服务器公网 IP 标注国家；订阅凭据及明文节点列表仅 root 可读。

VMess、Shadowsocks、WebSocket 和 gRPC 节点主要用于客户端兼容性测试，长期使用优先选择 VLESS Reality 或 VLESS TLS。需要 Hysteria2、TUIC、AnyTLS，或与现有服务共存时，请使用进阶多协议教程。
