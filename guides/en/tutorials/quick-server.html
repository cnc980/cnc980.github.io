Beginner one-click setup

From server login to a compatible client import

Bring your own Debian or Ubuntu cloud server and run two commands. The installer prints one HTTPS subscription URL containing seven protocols and ports, ready to import into a compatible client. No domain purchase is required.

Download installer Advanced guide
Before you begin

Use this only on a fresh server you own or are authorized to administer. The installer requires Debian or Ubuntu, root, and systemd. It stops without overwriting anything if a required port, Xray, or a a compatible client subscription service already exists.

Restored on 2026-11-10. Check the provider for current offers, fees and interface steps.

Only 4 steps

  1. Prepare a server
  2. Sign in with SSH
  3. Download and run
  4. Import into a compatible client

1. Prepare a server

  • Use a cloud server with a public IPv4 address and Debian 12/13 or Ubuntu 22.04/24.04.
  • Keep the server IP and root password handy, or prepare an SSH private key.
  • Allow TCP 22, 80, 443, 8388, 8443, 2053, 2083, 2087, 2096, and 9443, plus UDP 8388, in the cloud firewall.
  • If SSH uses a custom port, allow that port instead of TCP 22.
Never send your password to someone else. Type it only in your own terminal. It is normal for the password field to show no characters while you type.

2. Sign in with SSH

Open Terminal on a Mac or PowerShell on Windows. Replace the placeholder with your server's public IP:

ssh root@YOUR_SERVER_IP

On the first connection, type yes, then enter the root password. A prompt such as root@server:~# means you are signed in.

Example: ssh root@203.0.113.10. The example address is documentation only and cannot be used as a real server.

3. Download and run the installer

After signing in, run these two lines. The script is downloaded first so you can inspect it instead of piping an unseen download directly into Bash.

curl -fsSL https://spellv.com/downloads/serverkit-quick-server.sh -o serverkit-quick-server.sh
bash serverkit-quick-server.sh

To read the script before running it, insert this command between the two lines:

less serverkit-quick-server.sh

The installer validates the system and ports, verifies the official Xray download, generates unique credentials, detects the server's real country, enables Xray and Nginx at boot, and obtains a trusted IP HTTPS certificate with automatic renewal. If UFW is active, the required rules are added without enabling a firewall unexpectedly.

TCP 80 must be publicly reachable. It is required to issue and renew the IP certificate. The node ports and subscription port 9443 must also be allowed by the provider's firewall.

4. Import into a compatible client

When installation succeeds, the terminal displays a URL shaped like https://SERVER_IP:9443/sub/RANDOM_KEY.

  1. Copy the complete HTTPS subscription URL, including its random key.
  2. Open a compatible client and tap Add or the “+” button.
  3. Choose Subscription or Import from URL, paste it, and save.
  4. Refresh the subscription, then select any of the seven nodes and connect.

To show the subscription URL again later, sign in to the server and run:

cat /root/serverkit-subscription-url.txt
Country labels show the real exit location. All seven nodes from one server display the same country code. Real US, Japan, or Singapore routes require separate servers in those countries.

If it does not connect

systemctl status xray nginx --no-pager
journalctl -u xray --no-pager -n 50
ss -lntup | grep -E ':443|:8388|:8443|:2053|:2083|:2087|:2096|:9443'
  • Confirm that the server address in a compatible client matches the cloud server's public IP.
  • Confirm the cloud security group allows every listed node port, certificate port 80, and subscription port 9443.
  • Switch between Wi-Fi and cellular data to rule out a restriction on the current network.
  • Credentials are stored in a root-only file. Do not publish them or commit them to a repository.

What does the installer create?

Seven protocol nodesVLESS Reality, Shadowsocks, VMess WS/TLS, VLESS TLS, Trojan TLS, VLESS gRPC/TLS, and Trojan WS/TLS.
HTTPS subscription · TCP 9443A trusted short-lived IP certificate is issued and renewed automatically, with safe service reloads.
Real country labelThe server's public IP determines the country. Credentials and the decoded node list remain root-only.

VMess, Shadowsocks, WebSocket, and gRPC are included mainly for client compatibility testing; prefer VLESS Reality or VLESS TLS for ongoing use. For Hysteria2, TUIC, AnyTLS, or coexistence with existing services, use the advanced multi-protocol guide.
