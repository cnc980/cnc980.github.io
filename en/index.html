VPN XX · 6787351160

VPN XX for iOS 1.0.8 is an advertising-supported subscription and node configuration manager. This released version accepts only configurations and URLs supplied by users and contains no preset network subscription sources. It organizes, tests, and shares configuration records; it does not establish a system VPN tunnel or supply a VPN traffic service.

Product detailsSupportPrivacy

VPN XX PRO · 6788285855

VPN XX PRO for iOS 1.0.7 and Mac 1.0.1 are paid, ad-free configuration managers. Both released versions include Network Source: users can select preset third-party public subscription sources hosted on GitHub and import the returned node records. This feature is in addition to users' own imports. These public sources are not developer-owned servers and their contents can change. The app itself does not establish a system VPN tunnel.

Product detailsSupportPrivacy

SpellVPN Tool · 6788655739

SpellVPN Tool is a paid, ad-free configuration client for iOS and macOS. It supplies no server nodes, preset source catalog, or node-service subscription. Import your own configuration, nodes, or subscription URL that you are authorized to use. The client can establish a VPN connection using the imported configuration; it is not an offline-only file viewer.

Product detailsSupportPrivacy

SpellVPN Ultra · 6790699220

SpellVPN Ultra is the iOS edition with advertising and optional App Store auto-renewing subscriptions. A valid subscription removes ads and gives access to Curated Sources and Exclusive Lines supplied through the service. Ultra also supports users' own imports. These service-provided configurations are an actual subscription benefit, not just ad removal.

Product detailsSupportPrivacy
