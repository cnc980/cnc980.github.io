VPN XX

App Store ID: 6787351160

Developer-confirmed distributed iOS version: 1.0.8. Advertising-supported configuration manager.

Product disclosureTXT

Release history and developer statement

The developer confirms that distributed VPN XX iOS 1.0.8 accepted user-supplied configurations and URLs and contained no preset public subscription sources. It manages node records and does not create a system VPN tunnel. Although App Store Connect displayed a distributable status, the developer reported storefront unavailability and the same account notice in this app's review messages.

What the inspected material supports

The current shared development tree does contain an experimental public-source catalog. It is disclosed here rather than treated as evidence about an earlier upload. No matching historical VPN XX 1.0.8 archive or upload receipt was available in this audit, so the no-preset statement is identified as the developer's release-history confirmation. PRO's distributed-source feature is documented separately.

Next steps / not yet verified as complete

Before any new free-edition submission we will exclude preset sources and verify the exact archive. The earlier mainland China inquiries sought clarification of storefront availability. There is no evidence that those inquiries caused the account action; this appeal does not request mainland China distribution. We ask Apple to identify any VPN XX build or communication relied upon.

How to read this evidence

The record combines developer-confirmed release history, current local source excerpts, local metadata drafts, and two original developer-supplied form screenshots. These are different evidence types. No exact historical upload archives, Apple upload receipts, production service authorization documents, or new App Store approvals are included. A SHA-256 digest identifies the captured bytes; it does not certify that Apple reviewed or received them. Selected excerpts are not an exhaustive code or binary audit.

This is a public, sanitized record with identical content for all readers. It omits personal account identifiers, private correspondence, node credentials and working public subscription URLs. It is not password protected. Original materials can be provided privately to Apple through an appropriate channel if requested. Search-engine noindex is a preference, not access control.
