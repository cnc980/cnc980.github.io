02 / ACCOUNT & APP SAFETY

账户安全与使用规范

把账户权限、凭证管理和应用质量放在同一份日常检查清单里。

01 / 05

用团队角色协作

团队成员使用各自的 Apple Account，通过用户邀请和角色授权参与开发。按工作需要授予权限，定期移除不再需要的访问；无需通过共享账户密码来协作。

02 / 05

保护登录与签名凭证

  • 启用双重认证，妥善管理受信任设备与号码。
  • 不要公开密码、验证码、私钥或 API Key；敏感文件不应放入公开代码仓库。
  • 对证书、描述文件和 API Key 建立归属记录，仅向需要的人提供访问。

03 / 05

让描述与实际功能一致

上架前核对名称、截图、描述和真实功能，检查第三方 SDK 的行为与数据收集。应用涉及的素材、商标和服务须具备相应使用权，避免提交重复或误导性的应用。

04 / 05

收到审核问题后怎么处理

先阅读具体审核意见，结合对应规则修正功能或资料，再在原应用记录中回复和提交。需要登录的功能应向审核人员提供有效测试方式。保存沟通记录并按通知要求处理。

05 / 05

账户与审核状态如何判断

以 Apple 后台状态和官方通知为准。设备、网络或操作习惯不能替代内容与权限要求，也无法据此保证账户永不受限或应用一定通过审核。
