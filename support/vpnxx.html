Editions and version information

VPN XX · iOS 1.0.8

VPN XX for iOS 1.0.8 is an advertising-supported subscription and node configuration manager. This released version accepts only configurations and URLs supplied by users and contains no preset network subscription sources. It organizes, tests, and shares configuration records; it does not establish a system VPN tunnel or supply a VPN traffic service.

VPN XX PRO · iOS 1.0.7 / Mac 1.0.1

VPN XX PRO for iOS 1.0.7 and Mac 1.0.1 are paid, ad-free configuration managers. Both released versions include Network Source: users can select preset third-party public subscription sources hosted on GitHub and import the returned node records. This feature is in addition to users' own imports. These public sources are not developer-owned servers and their contents can change. The app itself does not establish a system VPN tunnel.

Planned changes

Planned replacement versions will remove preset public sources while retaining user-supplied imports. This is a future change: updating this website does not remove the feature from PRO iOS 1.0.7 or Mac 1.0.1 already installed on a device. No replacement release or restoration date is announced.

Configuration sources and network requests

Configuration sources and network requests

Importing or refreshing a URL sends a request to that source; node latency and reachability checks contact the relevant endpoints. VPN XX PRO iOS 1.0.7 and Mac 1.0.1 also contact public subscription sources on raw.githubusercontent.com when the Network Source feature is used. Source operators receive network request information such as IP address and HTTP metadata. Imported records can be stored locally and synced through private iCloud when enabled. VPN XX iOS 1.0.8 has no preset source catalog.

Common Questions

What does VPN XX do?

VPN XX manages subscription URLs and proxy node information. It helps import, refresh, organize, share, and test nodes.

Does VPN XX provide VPN servers?

VPN XX iOS 1.0.8: user-supplied imports, with ads. PRO iOS 1.0.7 / Mac 1.0.1: ad-free, with user imports and preset third-party Network Source imports. Both manage configurations rather than creating a VPN tunnel.

Which VPN XX edition has ads?

VPN XX iOS 1.0.8: user-supplied imports, with ads. PRO iOS 1.0.7 / Mac 1.0.1: ad-free, with user imports and preset third-party Network Source imports. Both manage configurations rather than creating a VPN tunnel.

Why does the free edition ask for advertising consent or tracking permission?

VPN XX Free uses Google UMP consent forms where required and may request App Tracking Transparency permission before personalized advertising. Pro is a paid download and does not initialize advertising SDKs.

Why do some speed tests fail?

Latency and reachability depend on the protocol, endpoint, network, subscription provider, and whether the imported node supports the app's test method.

How do I delete data?

Use the app's settings to clear local data, restore from iCloud, clear iCloud data, or clear both local and iCloud data.
