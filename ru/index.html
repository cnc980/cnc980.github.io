EasyTallys — приложение учета финансов с локальным хранением и необязательной синхронизацией и совместным доступом через Apple CloudKit. Версии и функции

EasyTallys · 6795085919

EasyTallys — приложение учета финансов с локальным хранением и необязательной синхронизацией и совместным доступом через Apple CloudKit. В нем нет рекламы, встроенных покупок App Store, платного членства или сервера финансовых данных разработчика. Напоминания о подписках — записи счетов, созданные пользователем, а не покупки в приложении.

О продуктеПоддержкаКонфиденциальность

VPN XX · 6787351160

VPN XX для iOS 1.0.8 — менеджер подписок и конфигураций узлов с рекламой. Эта выпущенная версия принимает только конфигурации и URL пользователя и не содержит готовых сетевых источников подписок. Она упорядочивает, проверяет и передает записи конфигураций, но не создает системный VPN-туннель и не предоставляет VPN-трафик.

О продуктеПоддержкаКонфиденциальность

VPN XX PRO · 6788285855

VPN XX PRO для iOS 1.0.7 и Mac 1.0.1 — платные менеджеры конфигураций без рекламы. Обе выпущенные версии содержат Network Source: пользователь выбирает готовые сторонние публичные источники подписок на GitHub и импортирует полученные узлы. Собственный импорт также поддерживается. Эти источники не являются серверами разработчика, а их содержимое может меняться. Само приложение не создает системный VPN-туннель.

О продуктеПоддержкаКонфиденциальность

SpellVPN Tool · 6788655739

SpellVPN Tool — платный клиент конфигураций для iOS и macOS без рекламы. Он не предоставляет серверные узлы, каталог готовых источников или подписку на узлы. Пользователь импортирует собственные конфигурации, узлы или URL подписки, которыми вправе пользоваться. Клиент может устанавливать VPN-соединение по импортированной конфигурации; это не только автономный просмотрщик файлов.

О продуктеПоддержкаКонфиденциальность

SpellVPN Ultra · 6790699220

SpellVPN Ultra — версия для iOS с рекламой и необязательными автопродлеваемыми подписками App Store. Действующая подписка убирает рекламу и открывает Curated Sources и Exclusive Lines, предоставляемые сервисом. Ultra также поддерживает собственный импорт. Конфигурации сервиса являются отдельным преимуществом подписки, а не просто отключением рекламы.

О продуктеПоддержкаКонфиденциальность

ArtCut · 6788636979

ArtCut и ArtCut Pro — отдельные версии видеоредактора с общими основными функциями. ArtCut бесплатен и содержит рекламу; ArtCut Pro — платная версия без рекламы.

ArtCut Pro · 6790354436

ArtCut и ArtCut Pro — отдельные версии видеоредактора с общими основными функциями. ArtCut бесплатен и содержит рекламу; ArtCut Pro — платная версия без рекламы.

Руководства приложений

Инструкции по функциям приложений: импорт, покупки, хранение данных и устранение неполадок.

Руководство SpellVPN

Следуйте реальному пути Dashboard → + → Import → Nodes → Connect, затем изучите обновление подписки, DNS, Ping, диагностику и действия при подключенном туннеле без трафика.

Руководство VPN XX

Используйте VPN XX для импорта, обновления, организации, синхронизации, отправки и проверки предоставленных пользователем URL подписок и proxy-узлов.

Руководство ArtCut

Создавайте локальные видеопроекты, редактируйте клипы на таймлайне, добавляйте субтитры и наложения, настраивайте звук и экспортируйте видео.

Руководство EasyTallys

Настройте книги и счета, записывайте операции с OCR чеков, смотрите бюджеты и отчеты, отслеживайте регулярные счета, используйте быстрый ввод Widget и Watch и защищайте локальные финансовые данные.
