Версии и функции

EasyTallys

EasyTallys — приложение учета финансов с локальным хранением и необязательной синхронизацией и совместным доступом через Apple CloudKit. В нем нет рекламы, встроенных покупок App Store, платного членства или сервера финансовых данных разработчика. Напоминания о подписках — записи счетов, созданные пользователем, а не покупки в приложении.

Поддержка

Поддержка

Для проверки синхронизации откройте настройки iCloud в приложении и проверьте фактическое состояние учетной записи и синхронизации. Совместный доступ CloudKit требует соответствующих прав Apple. Снимок экрана, локальный тест или ожидающая проверки версия не подтверждают синхронизацию вашего устройства. Перед диагностикой сохраните резервную копию.

Какие данные мы собираем

Текущая версия EasyTallys не содержит рекламных SDK, сторонних SDK аналитики, учетной записи разработчика, сервера финансовых данных разработчика, StoreKit-продуктов, членства или paywall. Мы не продаем пользовательские данные и не передаем их для рекламы.

Финансовые данные

EasyTallys хранит созданные вами книги учета, счета, категории, теги, продавцов, проекты, участников, записи соавторов и добавленные вами контактные данные, статус приглашений, метаданные CloudKit Sharing, операции, бюджеты, регулярные шаблоны, подписки, данные кредитных карт, рассрочки, курсы валют, заметки, изображения чеков, результаты OCR и связанные настройки.

Локальное хранение, App Group и iCloud

Финансовые данные хранятся локально на вашем устройстве. Если включить iCloud-синхронизацию, приложение синхронизирует данные через ваш приватный iCloud с помощью CloudKit. Widget, Apple Watch и основное приложение могут обмениваться локальными данными и настройками через App Group, настроенную для приложения.

CloudKit Sharing и удаленные уведомления

Если вы используете общие книги, системный CloudKit Sharing Apple может обрабатывать ссылки приглашений, отображаемые имена участников, роли, добавленные вами контактные данные, состояние приглашений и снимки общих книг через ваш iCloud. Приложение может регистрировать уведомления CloudKit об удаленных изменениях, чтобы системы Apple могли будить приложение для безопасной синхронизации общих изменений; эти уведомления не отправляют ваши финансовые данные на сервер разработчика.

OCR и файлы

OCR чеков или счетов использует локальный фреймворк Apple Vision для выбранных вами изображений. Доступ к файлам используется только когда вы импортируете, экспортируете, создаете резервную копию, восстанавливаете или выбираете файлы чеков и счетов.

Импорт, экспорт и удаление

Приложение может импортировать или экспортировать JSON, CSV, Excel, PDF, ZIP, OFX и QIF, когда вы выбираете эти действия. Импорт банковских CSV может распознавать распространенные заголовки debit, credit, account, status, currency, transaction number и description. Вы можете очистить локальные данные или данные iCloud sync из приложения.

Биометрическая блокировка

EasyTallys может использовать Face ID, Touch ID или системную аутентификацию для блокировки приложения. Биометрия обрабатывается iOS, iPadOS или macOS; приложение не получает ваши биометрические данные.

Cold Wallet Vault

Cold Wallet Vault может содержать введенные вами адреса кошельков, seed-фразы, private keys, Keystore JSON, заметки о backup hardware wallet, contract addresses, network labels, tags и локальные напоминания. Секреты кошельков хранятся в локальном Keychain с this-device-only protection. Они не синхронизируются через iCloud или CloudKit Sharing, не записываются в общие книги и не входят в JSON, ZIP, CSV, Excel, PDF или отчеты. После удаления записи или потери device-only Keychain item приложение не может восстановить секрет.

Уведомления

После разрешения уведомлений приложение может использовать локальные уведомления для подписок, регулярных записей, бюджетов, срока депозитов, выплат по кредитной карте и рассрочек.

Конфиденциальность детей

EasyTallys не предназначено для детей и не собирает сознательно персональные данные детей.

Изменения
