# 美国免税州地址生成器

独立静态网站。打开 `index.html` 即可使用，不需要服务器。

功能：

- 支持中文、英文、俄文三语切换。
- 选择 Delaware、Oregon、Montana、New Hampshire、Alaska。
- 一键生成带 TEST DATA 标记的测试地址。
- 随机选择免销售税州和真实常见城市 / ZIP 组合。
- 根据用户填写的真实街道地址，生成 Apple Account 账单地址格式。
- 支持复制生成结果。
- 支持保存和导出浏览器本地地址结果。
- 提供合法真实地址来源入口：CMRA、UPS Store 邮箱、虚拟邮箱服务和 USPS 地址校验。

当前测试数据池：

- 5 个免销售税州。
- 70 组真实常见城市 / ZIP 组合。
- 30 个测试姓名。
- 300 个自然风格合成测试街道组合。
- 门牌号随机，电话使用对应州区号 + 555 测试号码。

合规说明：

测试数据模式生成的地址仅用于开发、表单测试、排版预览或教程演示，不应用于 Apple Account、账单、税务、收货、退货或转运。测试用途说明保留在结果末尾，街道地址行不额外追加 `(TEST DATA / 测试数据)`。真实地址模式下，用户应只填写自己真实可用或获得授权使用的地址。
