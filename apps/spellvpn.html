Import options

Use QR scan, photo QR, clipboard, Files, Wi-Fi Upload, subscription URLs, proxy links, and URL schemes. Supported inputs include sing-box JSON, Clash/Mihomo YAML, Base64 URI lists, SIP008, Surge, Quantumult, Shadowrocket-style text, and common proxy links.

Nodes and subscriptions

Manage saved subscription URLs, update or copy them, choose nodes, edit real proxy outbounds, export a single node as JSON, and show node QR codes.

Profiles, tools, and widgets

Use connection profiles, VPN pause, privacy filters, DNS management, Network Tools for TCP Ping, DNS, IP, Whois, GeoIP, TLS, HTTP, TCP/UDP, IPv6, and speed tests, Home/Lock Screen widgets, basic App Shortcuts, local logs, diagnostics, JSON export/import, and iCloud Drive backups.

Ultra, iOS Paid, and Mac Paid

Ultra is free with Yandex/AdMob ads; auto-renewing subscriptions remove ads and unlock Ultra features. The paid App Store listing at https://apps.apple.com/app/id6788655739 covers the paid iOS edition and the paid Mac edition. The macOS build is a separate native macOS target with no advertising SDKs, analytics SDKs, StoreKit products, subscriptions, or built-in VPN account.

macOS App Store build

The paid Mac version is now available on the Mac App Store at the same paid App Store listing, https://apps.apple.com/app/id6788655739. It is a native macOS client with its own Packet Tunnel Provider. It imports sing-box JSON, Clash/Mihomo YAML, common proxy links, SIP008 Shadowsocks JSON, WireGuard text, QR codes, clipboard text, files, and remote configuration URLs. It manages profiles, node groups, favorites, source updates, rules, local privacy filters, Relay / MultiHop, diagnostics, encrypted backups, and menu bar connect/disconnect. The macOS target has no ad SDKs, analytics SDKs, StoreKit products, subscriptions, provider-lines service, or built-in VPN account.

Important Boundaries

SpellVPN does not sell proxy nodes or host user traffic. Both iOS and Mac versions require users to bring configurations and servers they are authorized to use. The macOS version uses its own Packet Tunnel Provider, Bundle ID/App Group, and Network Extension entitlement; it does not include the iOS Ultra advertising SDKs, subscriptions, or StoreKit products. The current build does not claim MITM, Rewrite scripts, native OpenVPN, or IKEv2 configuration import.
